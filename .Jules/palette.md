## 2023-10-27 - Tooltips on Disabled Elements
**Learning:** Native OS tooltips (using the HTML `title` attribute) do not appear on disabled buttons because disabled elements swallow mouse events and cannot receive keyboard focus, harming accessibility for users who need context on why an action is unavailable.
**Action:** Wrap the conditionally disabled button in a `<span>` containing the `title` attribute. Apply `tabIndex` conditionally on the wrapper (e.g., `tabIndex={!canExport ? 0 : undefined}`) to make the disabled state keyboard focusable without creating a double tab-stop when enabled. If the button is inside a flex/grid layout, style the wrapper with `inline-flex` and size utilities (e.g., `className="inline-flex w-full min-w-0"`) and set the inner button to `width: 100%` (`w-full`) to maintain the expected layout.
