## 2026-05-30 - Improve disabled state UX
**Learning:** Users can be confused when buttons are disabled without explanation. Adding dynamic tooltips explaining the reason for the disabled state improves UX, as well as indicating what the button does when enabled.
**Action:** Always add dynamic `title` attributes (tooltips) that clearly explain the reason for the disabled state when disabled, and what the button does when enabled, for conditionally disabled buttons.
