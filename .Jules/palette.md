## 2024-08-23 - Explaining disabled buttons without breaking layout
**Learning:** Adding a `title` (tooltip) natively to explain a disabled state doesn't work if placed directly on the `disabled` button because disabled elements swallow mouse interactions and aren't focusable. Wrapping them in a `span` with `title` and conditional `tabIndex` solves accessibility, but if that wrapper is in a CSS grid (like `export-grid`), it can break layouts unless `inline-flex w-full min-w-0` is added to the wrapper and `w-full` is passed to the button inside.
**Action:** Whenever wrapping components for tooltip/accessibility reasons within strict grid or flex layouts, enforce `display: inline-flex`, `width: 100%`, and reset `min-width: 0` on the wrapper, and map `w-full` to the inner button to guarantee layout continuity.
