## 2024-07-01 - Disabled Button Tooltips with Grid Layouts
**Learning:** In Chitra Studio's UI (specifically the `ExportPanel` grid layout), native HTML `<button>` elements that are conditionally disabled swallow mouse and keyboard events, preventing standard `title` tooltips from appearing. Because these buttons are within a `export-grid` CSS grid layout, directly wrapping them requires the wrapper to inherit the button's layout dimensions to prevent visual regressions.
**Action:** Always wrap conditionally disabled buttons in a `<span>` with the `title` attribute. To preserve grid/flex layouts and maintain accessibility without double tab-stops: use `display: inline-flex` and `width: 100%` on the wrapper (e.g., `className="inline-flex w-full"`), and apply `tabIndex={!canExport ? 0 : undefined}` to conditionally enable keyboard focus only when the button itself is disabled.
