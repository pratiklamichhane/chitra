## 2024-05-18 - Tooltips on disabled flex/grid buttons
**Learning:** Native `disabled` buttons swallow pointer events and cannot show tooltips on hover. Wrapping them in a `span` with `title` and `tabIndex` works, but if the button is within a grid or flex layout, the `span` wrapper must use `display: inline-flex` (e.g. `className="inline-flex"`) with appropriate width settings (e.g. `w-full min-w-0`) and the child button must also span full width (`w-full`), otherwise the wrapper disrupts the parent layout structure. Also, conditionally apply `tabIndex` so active buttons don't receive double focus.
**Action:** When adding tooltips to disabled buttons in layout containers, use `inline-flex w-full min-w-0` on the wrapper, apply `w-full` to the inner button, and make `tabIndex` conditional.
