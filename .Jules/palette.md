## 2024-05-19 - Accessible Tooltips for Disabled Grid Buttons
**Learning:** Native tooltips (`title`) do not display on `disabled` buttons because disabled elements do not emit mouse events or receive keyboard focus. Wrapping them in a `<span title="..." tabIndex="0">` solves the focus/event issue, but requires layout care. For buttons inside a CSS grid or flexbox, the wrapper must act as the flex/grid item (`display: inline-flex w-full min-w-0`), and the inner button must expand to fill it (`w-full`), otherwise the layout collapses or overflows.
**Action:** Always wrap disabled buttons in focusable containers to expose explanation tooltips. If within a grid/flex layout, apply sizing classes (`w-full min-w-0`) to the wrapper to preserve the structural design, and ensure the button expands to fill the wrapper. Apply `tabIndex` conditionally (`tabIndex={!isEnabled ? 0 : undefined}`) to prevent a double tab-stop accessibility regression when the button is enabled.
