## 2024-07-09 - Accessible Tooltips for Conditionally Disabled Buttons
**Learning:** Disabled HTML elements swallow mouse events and cannot receive keyboard focus, meaning native tooltips (`title` attributes) on disabled buttons do not appear. This makes it impossible for users to know *why* an action like "Export PNG" is disabled without external hints.
**Action:** To provide explanatory tooltips on conditionally disabled buttons without breaking layout or accessibility, wrap the button in a `<span>`. Apply the `title` attribute to the `<span>`. Crucially, add a conditional `tabIndex` to the wrapper (e.g., `tabIndex={!canExport ? 0 : undefined}`) so it becomes focusable *only* when the button is disabled, avoiding a double tab-stop when the button is enabled. If the button is in a flex/grid layout, set `className="inline-flex"` on the `<span>` to preserve styling. Remove the `title` from the button itself to prevent redundant native tooltips when enabled.
