## 2024-09-08 - Accessible Tooltips for Disabled Buttons in Grid Layouts
**Learning:** Native `disabled` HTML buttons swallow mouse and focus events, making `title` tooltips inaccessible. Wrapping the disabled button in a `<span title="...">` solves this, but it disrupts CSS grid or flex layouts if not styled correctly. Furthermore, conditionally applying `tabIndex={0}` to the wrapper only when disabled ensures keyboard accessibility without introducing double tab-stops when the button is enabled.
**Action:** When adding accessible tooltips to disabled buttons within flex/grid layouts, use a wrapper like `<span className="inline-flex w-full min-w-0" title={isDisabled ? "Reason" : undefined} tabIndex={isDisabled ? 0 : undefined}>` and ensure the inner button has a `w-full` class.
