## 2024-06-25 - Disabled Buttons and Tooltips
**Learning:** Native `disabled` HTML attributes on buttons cause them to swallow mouse events and prevent them from receiving keyboard focus. This means standard `title` tooltips placed directly on disabled buttons will not appear for mouse users and the elements are entirely skipped by screen readers / keyboard users, making the reason for the disabled state opaque.
**Action:** When a button is disabled and its state needs explanation, wrap it in a `<span>` containing the `title` attribute. Apply `tabIndex` to the wrapper conditionally (e.g., `tabIndex={!canExport ? 0 : undefined}`) so that keyboard users can tab to the wrapper *only* when the button is disabled (preventing double tab stops when enabled). Use `inline-flex` on the wrapper (and `w-full` if necessary on both wrapper and button) to ensure the layout is preserved.
