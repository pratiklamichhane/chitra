## 2024-08-16 - Disabled Button Tooltips with Keyboard Accessibility
**Learning:** Adding a `title` to a natively `disabled` button fails to show a tooltip because disabled elements do not trigger mouse events and cannot receive keyboard focus. Additionally, Playwright makes testing native browser tooltips (`title`) difficult, requiring custom script evaluation to visualize them or checking attributes.
**Action:** Always wrap disabled buttons in a `span` with the `title` attribute. To ensure keyboard accessibility, conditionally apply `tabIndex={0}` to the span *only* when the button is disabled, so screen reader/keyboard users can discover why the action is blocked, but avoid double tab-stops when the button is enabled. Use `inline-flex` and appropriate width constraints to preserve layout.
