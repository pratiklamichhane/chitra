## 2024-10-29 - [Tooltips on Disabled Buttons]
**Learning:** In React, disabled buttons swallow mouse events, preventing native tooltips (`title` attribute) from appearing.
**Action:** Wrap the disabled button in a `<span>` containing the `title` attribute. Apply `tabIndex` conditionally on the wrapper (e.g., `tabIndex={!canExport ? 0 : undefined}`) to prevent a double tab-stop accessibility regression when the button is enabled. Avoid using CSS `display: contents` on the wrapper; this removes it from the accessibility tree and breaks hover/focus interactions. Ensure the wrapper's `title` conditionally falls back to the original title when the button is enabled (e.g., `title={canExport ? 'Original Title' : 'Disabled Reason'}`) so sighted users continue to see the native tooltip.
