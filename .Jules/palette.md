## 2026-05-18 - Added Tooltips to Disabled Export Buttons\n**Learning:** Users can find disabled buttons frustrating without context. While native `title` tooltips on `disabled` buttons might not show on hover in all browsers (due to pointer events being absorbed), adding descriptive tooltips to button states provides better semantic context for accessibility tools and is a very low-effort, low-risk way to improve the interface when full tooltip components aren't available.\n**Action:** Apply descriptive `title` attributes explaining both the enabled action and the reason for the disabled state to conditional buttons.
