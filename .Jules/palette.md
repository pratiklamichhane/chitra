## 2024-06-25 - Native Tooltips for Disabled Buttons
**Learning:** Native disabled buttons (`disabled={true}`) swallow pointer events and cannot receive keyboard focus, meaning standard `title` attributes placed directly on them will not be visible to users or screen readers.
**Action:** When conditionally disabling a button, wrap it in a `<span>` element. Apply the `title` attribute to the wrapper. To ensure accessibility for keyboard users, also conditionally apply `tabIndex={0}` to the wrapper *only* when the button is disabled (to avoid double-focus when enabled). Finally, ensure the wrapper preserves grid/flex layouts by using `className="inline-flex w-full min-w-0"` (or similar appropriate styles) while setting the inner button to `w-full`.
