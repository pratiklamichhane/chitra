## 2026-10-15 - Fixing Tooltips on Disabled Flexbox Buttons
**Learning:** Wrapping disabled buttons in `<span>` tags to show tooltips requires careful class management to preserve layout. In a flex container with `gap`, wrapping an element changes its behavior. Adding `w-full` to both the span and button caused horizontal stretching. The correct fix was to just use `<span className="inline-flex">` without any width classes, allowing the wrapped button to dictate the size.
**Action:** When wrapping a disabled button in a tooltip span to prevent mouse events from being swallowed, test it within its layout context. Only apply specific layout constraints if the original layout requires it (e.g. `flex: 1` vs `width: auto`), and typically just wrapping it in `inline-flex` is sufficient.
