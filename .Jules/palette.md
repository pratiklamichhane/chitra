## 2024-10-25 - Native Tooltips for Disabled Buttons
**Learning:** Native OS tooltips (`title` attribute) on disabled HTML buttons do not appear because disabled elements swallow mouse events. Furthermore, they remove the element from the document's sequential tab navigation order, breaking keyboard accessibility. Wrapping the disabled button in a `<span>` with the `title` attribute solves the hover issue, but keyboard focus still won't land on it by default.
**Action:** Always wrap disabled buttons in a `<span>` containing the `title` attribute. Conditionally add `tabIndex={0}` to the wrapper *only* when the button is disabled (e.g., `tabIndex={!isEnabled ? 0 : undefined}`). To maintain CSS grid or flex layouts, apply `className="inline-flex w-full min-w-0"` to the wrapper and `className="w-full"` to the button itself.
