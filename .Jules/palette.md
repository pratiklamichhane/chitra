## 2024-05-18 - Tooltips for conditionally disabled layout grid buttons
**Learning:** Disabled elements swallow pointer events and cannot receive focus, rendering native `title` tooltips useless. Wrapping them in a `span` restores tooltip capability, but adding `tabIndex={0}` to the span must be done *conditionally* (only when the inner button is disabled). If `tabIndex={0}` is always applied, it creates an inaccessible double tab-stop when the button is active. Also, when placing these wrappers inside CSS grid/flex layouts (like `.export-grid`), they must inherit dimensions safely (e.g., `inline-flex w-full min-w-0`) and pass full width down to the inner button to avoid layout collapse.
**Action:** Always condition `tabIndex={!isDisabled ? undefined : 0}` on the wrapper span, apply layout reset classes to the wrapper (`inline-flex w-full min-w-0`), and ensure the inner button can expand (`w-full`).
