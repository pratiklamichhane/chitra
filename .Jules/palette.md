## 2025-02-18 - Tooltips on Disabled Buttons using Wrapper Spans
**Learning:** Disabled HTML buttons swallow mouse events and cannot receive keyboard focus, meaning native `title` tooltips won't appear on them. Furthermore, attempting to capture focus on disabled buttons creates accessibility problems.
**Action:** Fix this by wrapping the disabled button in a `<span>` containing the `title` attribute. Conditionally apply `tabIndex={0}` to the wrapper *only* when the button is disabled (e.g., `tabIndex={!canExport ? 0 : undefined}`) to prevent a double tab-stop accessibility regression when the button is enabled. If the button is inside a flex or grid layout, the wrapper must use `display: inline-flex` with constraints like `min-width: 0` and `width: 100%`, and the button itself must use `width: 100%` to preserve layout integrity.
