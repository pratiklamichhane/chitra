## 2024-05-18 - Tooltips on disabled buttons inside grid layouts
**Learning:** HTML `disabled` attributes swallow mouse events and prevent keyboard focus, making native tooltips via `title` attribute impossible to trigger directly on the button. While wrapping the button in a `<span>` and applying the `title` attribute there works, if this is done inside a CSS Grid or Flex layout, the span wrapper can break the layout by disrupting width computations. Furthermore, blindly adding `tabIndex={0}` to the span wrapper introduces a double tab-stop accessibility issue when the button becomes enabled.
**Action:** When adding tooltips to conditionally disabled buttons in a layout (like a grid), wrap the button in a `<span>` with the `title` attribute. Conditionally apply `tabIndex={!isDisabled ? undefined : 0}` to prevent double tab-stops. Most importantly, ensure the span has `display: inline-flex`, `width: 100%`, and `min-width: 0` (e.g. `className="inline-flex w-full min-w-0"`) and apply `width: 100%` (e.g. `w-full`) to the inner button to preserve layout constraints and prevent overflow.
