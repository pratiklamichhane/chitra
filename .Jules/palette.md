## 2024-08-15 - Disabled Button Tooltips with Keyboard Accessibility
**Learning:** Native `disabled` HTML elements swallow pointer events, which prevents native `title` tooltips from rendering. Additionally, disabled elements are naturally removed from the document's tab sequence, preventing keyboard and screen reader users from accessing contextual information about *why* the element is disabled. While `aria-disabled` is an alternative, replacing true `disabled` attributes can introduce functional regressions if event handlers aren't manually guarded.
**Action:** The most robust, accessible pattern without rewriting component logic is to wrap the `disabled` element in a structural container (like `<span>`). Place the `title` attribute on this container. To ensure keyboard accessibility, conditionally apply `tabIndex={0}` to the container *only* when the inner element is disabled. It's critical to apply layout preservation classes (like `className="inline-flex w-full min-w-0"`) to the wrapper to prevent breaking CSS Grid or Flexbox layouts.
