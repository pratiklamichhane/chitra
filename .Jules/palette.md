## 2025-05-18 - Tooltips for disabled elements
**Learning:** Disabled HTML elements (like buttons) swallow mouse events and cannot receive keyboard focus, meaning native tooltips (`title` attribute) won't appear directly on them. To improve UX for conditionally disabled buttons, wrap them in a `<span>` containing the `title` attribute.
**Action:** When wrapping disabled elements, apply `tabIndex` conditionally (e.g., `tabIndex={!canExport ? 0 : undefined}`) to the wrapper to prevent double tab-stops when the button becomes enabled. Additionally, if the button sits within a flex or grid layout, ensure the wrapper utilizes `display: inline-flex` with full width (e.g., `className="inline-flex w-full"`) and apply full width to the inner button to maintain structural integrity.
