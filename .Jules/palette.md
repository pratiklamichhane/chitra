## 2024-05-18 - [Add Tooltips to Conditionally Disabled Buttons]
**Learning:** Native disabled buttons swallow mouse events and cannot receive keyboard focus, meaning users and screen readers cannot access native tooltips (`title` attributes) explaining *why* the button is disabled. This harms accessibility and usability.
**Action:** When conditionally disabling buttons, wrap them in a `<span>` element. Apply the `title` attribute explaining the reason for being disabled to the wrapper. Crucially, conditionally apply `tabIndex={!isEnabled ? 0 : undefined}` to the wrapper. This allows keyboard navigators and screen readers to access the disabled reason without creating a double tab-stop when the button is enabled. To preserve grid/flex layouts, use `className="inline-flex w-full"` on the wrapper and `className="w-full"` on the button.
